# Nutrishare--group-16

🍱 NutriShare – Smart Food Donation and Waste Management System

🌱 Turning Surplus Food into Someone's Next Meal

📌 About the Project

NutriShare is a web-based food donation and waste management platform designed to reduce food wastage and help people in need by connecting food donors with organizations and volunteers.

Every day, restaurants, hotels, bakeries, supermarkets, and event organizers discard large amounts of surplus food, while many people struggle to access nutritious meals. NutriShare aims to bridge this gap by providing a platform where surplus food can be shared instead of wasted.

The platform allows users to donate available food, explore food donations, and connect surplus food with people who need it.

🎯 Objectives

- Reduce food wastage through an organized donation platform.
- Connect food donors with NGOs, volunteers, and needy communities.
- Encourage responsible food management and social responsibility.
- Promote sustainable development and hunger reduction.
- Make food donation simple and accessible through a web platform.

✨ Key Features

- User Registration and Login: Provides a user interface for account registration and login.
- Food Donation: Allows donors to submit surplus food details.
- Available Food Listings: Displays available food donations.
- Food Search: Helps users find available food.
- Responsive Design: Designed to work on desktop and mobile devices.
- Simple Interface: Easy-to-use layout for donors and recipients.

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality
- GitHub – Version control and project hosting
- GitHub Pages – Website deployment

⚙️ How It Works

1. A donor visits the NutriShare platform.
2. The donor enters the available food details.
3. The food information is submitted through the donation form.
4. Available food details are displayed on the platform.
5. Users can browse and search the available food listings.
